## 目标

阵型里编号更小的士兵死亡后，编号最大的活着成员走到那个空槽上。高位留下空位，中间的人不要全体往前挤一格。

## 需求指令

编号 = Pattern 上 `Slot_*` 按名字排序后的下标（现有 `RefreshSlotsFromChildren`；`Slot_00` = 0）。战斗中换的是成员↔槽下标，不改预制体，不写回布阵存档。

在 `TryNotifyMemberLost`（`CombatDead` 与 Rebel 都算腾槽）里，若移除后该组仍 ≥ `MinMemberCount`：

- 找出仍存活成员的最大槽下标 `max`。
- 若死者下标 `< max`，把 `max` 上的人改挂到死者下标（他的 `FormationSlot` 世界点跟着变）。
- 若死者已经是 `max`，不换人，该高位变空。
- 同一帧多个腾槽：按空出的下标从小到大，每步都用**当时**的最大存活下标去补。
- 然后仍按剩余成员重算等级 overlay（与现在相同）。`RemainingHp` 钳制规则不变。

低于 Min：不递补，整组解散，规则与现在相同。

例：占用 0、1、2、3、4。1 死 → 4 号换到 1，占用变为 0、1、2、3。接着 0 死 → 3 号换到 0，占用变为 0、1、2。

Correctness 用纯数据锁走上面这个例子，并再断言「死的是当前最大编号时其它人的下标不变」。

## 不做

- 把 2 号、3 号依次改名为更小的编号（禁止压缩）
- 从士兵栏补新人进空槽
- 布阵编辑器里的槽位重排

## 验收

- [ ] 楔阵前排 `Slot_00` 或 `Slot_01` 死亡后，原最后一号走到该槽，队形前排被补上，最后一格变空
- [ ] 只死最后一号时，前面的人不动
- [ ] 死到低于 `MinMemberCount` 时该组解散，不出现半套递补
- [ ] Rebel 离组同样腾槽并递补
- [ ] 另一组的槽位不被这次死亡改写
