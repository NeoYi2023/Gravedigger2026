`ObstaclePathMode=视为目标`：怪物到当前追击士兵的 XZ 线段穿过障碍占地时，才靠近打这堵墙。每次 −1，用怪物自己的攻速和动作。线段不穿过就绕开。墙拆掉后继续追兵。

依赖：[03a-path-around-ignore](03a-path-around-ignore.md)。

选定方案 A：COC 覆盖层判定挡路墙，再交给现有追击与 −1 命中通道。

## 规则

- 只在 COC 读。推图、防守、搜打撤忽略本列。
- 判定：怪物中心到**当前追击士兵**中心的 XZ 线段穿过仍存活障碍的 1 格占地。
- 穿过才把该墙当临时目标：靠近并攻击，每次 −1，攻速与普攻动作用怪物自己的。
- 线段不穿过：与「视为障碍」相同，绕开。
- 墙拆掉后继续追当前士兵。
- 样例：`Monster_03` 已在 03a 配成 `视为目标`，对着 `Coc_Lv2_01` 上的同一类墙。

## Acceptance

- [ ] 「视为目标」的怪只在墙挡住去路时拆墙，每次 −1，拆完继续追兵
- [ ] 线段不穿过时仍绕开，不打墙
- [ ] 「视为障碍」/「无视障碍」行为与 03a 一致
- [ ] 推图 / 防守 / 搜打撤的怪物寻路与改表前一致
