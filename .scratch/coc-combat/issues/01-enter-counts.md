挖坟、商店、自动造兵的方格显示存档剩余次数。进入扣 1，剩余 0 不能进。COC 这一片仍可先不进战斗，但次数显示为剩余次数，进入不扣次。

## 规则

- 键 `SandboxProgress`：第一次见到某 `NodeId` 时，剩余次数等于表内 `RepeatEnterCount`，通关为否。之后改表不回写旧档。
- 挖坟 / 商店 / 自动造兵：剩余大于 0 才进入，进入立刻扣 1。
- COC：本片不实现战斗。剩余大于 0 时仍可用现有占位页返回；进入不扣次。占位页在 02 换成空地图。
- 不改各玩法模块内部，不调用 `TryAdvanceStage`。

## Acceptance

- [x] 新档第一次打开沙盘，四个样例方格的次数等于表内 3 / 1 / 5 / 2
- [x] 进入挖坟、商店或自动造兵后回到沙盘，对应次数少 1
- [x] 次数为 0 的方格点击不进入
- [x] 重进同一存档，次数仍是扣过之后的值
- [x] 改表中的 `RepeatEnterCount` 不把旧档次数改回去
