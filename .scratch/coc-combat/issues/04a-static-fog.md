按地图上的 `CocFogPolygon` 画出未探索黑雾，多边形内隐藏普通怪，并禁止把士兵洒进去。本片不挖洞、不变暗、不记探索。

依赖：03 已能洒兵和战斗。父片 [04-fog](04-fog.md)。选定方案：A 格子盖章。本片难度确认为 2。

## 规则

- 黑雾画在士兵和地图元素之上，与镜头滤镜、地图外缘雾分开。
- 多边形内透明度用 `UnexploredAlpha`（默认 0.9），能看见地图。
- 多边形内看不见普通怪。最终 BOSS 和小 BOSS 始终可见。
- 多边形以外仍可看见怪物，也可洒兵。
- 点击落在任一迷雾多边形内则这次不放人。点还必须在 NavMesh 可行走处且在空气墙外。
- 本片没有临时亮起和变暗。重进后仍是同一张静态雾。

- [x] 不能把士兵洒进多边形内
- [x] 多边形外仍可洒兵，且能看见怪物
- [x] 黑雾盖在士兵和地图之上，与镜头滤镜、地图外缘雾分开
