我方士兵进入占领点后激活。激活写入存档，区域按配置半径永久亮起，并可洒兵。按奖励表给同一难度的挖坟、商店或自动造兵增加剩余次数。

依赖：01 的次数存档，04 的迷雾。04 已落地。本片难度确认为 2。

选定方案：A（同格第四态）。进图重建雾格后，已激活占领点按半径把格盖成 `Permanent`；`ApplyReveal` 不改写这些格。透明度 0，格内可洒兵，怪可见。重进再按存档盖章，不重复加次数。

## 规则

- 半径来自 `CocCapturePointConfig`，是地面上的圆。
- 每个占领点只激活一次。再次进入不重复加次数。
- 目标节点必须是同一难度的挖坟、商店或自动造兵。已通关的目标不加次数。
- 永久亮起跨局保留。单局失败重进后，占领点仍然亮着，其余迷雾探索重置。
- 永久亮起圆内可以洒兵，即使它原来在黑雾多边形里。

## Acceptance

- [x] Excel 与 CSV 含占领点表和奖励表（保留表头第 1～2 行）
- [x] 士兵进入占领点后，配置半径内保持全透明，并能在其中洒兵
- [x] 对应挖坟、商店或自动造兵的剩余次数增加配置的数量
- [x] 退出再进入，占领点仍是激活的，且次数不会再加一次
- [x] 单局失败重进后，迷雾探索重置，永久亮起还在
