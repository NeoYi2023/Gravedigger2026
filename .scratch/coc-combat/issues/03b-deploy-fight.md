底部按 `ClassId` 分组洒兵。点地放走该组最前一名并立刻从士兵库删除；按住左键按间隔再放。洒出的士兵用现有选敌战斗。本片还没有迷雾，整张可行走地图都可洒。找不到敌人时先停住，不走向最终 BOSS。

依赖：03a 的刷怪。父片 [03-deploy-and-boss](03-deploy-and-boss.md)。

## 规则

- 卡牌按 `ClassId` 分组，显示职业名、数量、组内第一名外形。数量为 0 不显示。点击选中。
- 左键点地放走该组最前一名，并立刻从士兵库删除。按住左键每 `DeployHoldIntervalSeconds`（默认 0.3 秒）再放一名。点在空气墙或不可走处不放人。
- 有敌人时用现有选敌、移动和攻击。找不到敌人时停住。
- 场上出现我方士兵后，怪物沿用已有追击。场上没有我方时仍不追。
- 不布阵、不护盾、不失控、不发经验、不弹推图结算。本片点返回仍回沙盘且不扣次；已洒出的不回库。

## Acceptance

- [x] 选中卡牌后点地出现一名士兵，库内该职业数量减 1
- [x] 按住左键会连续放人
- [x] 点在空气墙或不可走处不放人
- [x] 士兵会攻击进入范围的敌人；没有敌人时不走向最终 BOSS
- [x] 没洒出的士兵还在库里；已洒出的不回来
