按地图上的迷雾多边形画黑雾，并限制洒兵。难度 3，已拆成两片，一次会话只做最前面一片未完成的。选定方案：A 格子盖章（地面格宽 0.25）。04b 落地方案 A：同格三态就地更新。

- [04a 静态黑雾与禁洒](04a-static-fog.md)
- [04b 临时亮起、变暗与重进重置](04b-reveal-dark.md)

依赖：03 已能洒兵和战斗。本片不包含占领点的永久亮起（见 05）；没有永久亮起时，只有多边形以外可以洒兵。

## 规则

- 黑雾画在士兵和地图元素之上，与镜头滤镜、地图外缘雾分开。
- 无士兵信息：多边形内透明度 0.9，能看见地图，看不见普通怪。最终 BOSS 和小 BOSS 始终可见。
- 临时亮起：我方士兵周围地面半径 2，透明度 0，能看见怪。圆内普通怪记为已发现。
- 变暗：士兵死亡或离开后，曾亮起的区域透明度 0.7。已发现且站在变暗区或多边形外的普通怪保持可见；走进仍未探索的区域则重新隐藏。
- 临时亮起和变暗区域不能洒兵。
- 重进一局后探索重置。
- 半径是地面上的圆。

## Acceptance

- [x] 开局多边形内看不见普通怪，仍能看见最终 BOSS 和小 BOSS
- [x] 士兵走进多边形后，周围半径 2 变透明并能看见普通怪
- [x] 士兵离开或死亡后，该区域变暗，已经发现的普通怪仍然可见
- [x] 不能把士兵洒进多边形内
- [x] 退出再进入后，迷雾探索恢复成开局
- [x] 编码前已选定并记下实现方案
