怪物烘焙源。ModelId=`MonsterModel_02`。美术来源：`2D Zombie Pack 1` / `ZombieMonster2`（2880×1536，192px/格）。
Prefab：`Assets/Prefabs/Defend/Monsters/MonsterModel_02.prefab`（`Visual.localScale = 2/3` 与 128px 怪物对齐）。

离线烘焙：`python Tools/bake_monster_model_02_from_zombie.py`；Unity 内：`Tools/Gravedigger/Art/Repair Character Creator Export` → `Wire Monster Die2 Animators` → `Assemble Monster Model Prefabs`。
