# Domain docs

**Authority order:** `SPEC_*.md` > `CONTEXT.md` (glossary only) > `docs/adr/` (architecture decisions) > `AGENTS.md`

- `CONTEXT.md` links to SPEC; it must not duplicate rule text or numeric tables
- Put architecture decisions in `docs/adr/`; do not put game rules in ADRs
- When grilling, write rules into SPEC (bilingual) and add glossary rows to CONTEXT only
